# v0.1.2

## 本次更新

- 短音频省去重复切片；长音频每段最多60秒、最多两段并发转写，结果按录音顺序保存。
- 保存乱序完成的分段和准备好的音频缓存，失败重试只补未完成部分；兼容旧转写检查点。
- 短转写直接成稿并对照原文核查，长转写的事实提取和必要合并最多两路并发。
- 纪要根据实际主题、讨论脉络选择段落、要点和小标题，不强制栏目、章节顺序或字数；保留必要背景、观点理由和有依据的决定/待办。
- 模型列表按账号缓存并合并同时请求，手动刷新仍强制联网。
- 修复后台生成与改名/删除的冲突，生成请求及令牌刷新绑定所属账号。
- 原生标准WAV快速准备；修正iOS切片时长与Android一致为60秒。

## 验证与边界

- 23组、79项业务测试通过，TypeScript、4项构建脚本测试和部署配置检查通过。
- Android公网Debug已安装；13秒、60秒、156秒样本完成转写和本机保存。最终自适应结构提示v8通过回归测试；不同真实会议的输出仍需持续验证。
- 本版优化客户端处理，并未解决所有公网等待。一分钟有效语音样本仍约125秒，主要等待发生在公网ASR/LLM请求响应阶段；不承诺固定提速比例。
- iOS源版本已同步，但本次未构建或发布IPA。
