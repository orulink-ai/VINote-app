# VINote App 0.2.0

状态：源码交付候选，尚未推送或发布。版本由此前 0.1.3 统一调整为 0.2.0，本次交付不再重复升版；Android versionCode 为 9，iOS build 为 5。

## 产品范围

- 导航整合为会议与笔记、文件库、插件，账号与设置由头像进入；保留查询、项目、归档及上下文返回。
- 正文、版本、编辑历史、回收站及当前设备原件分别管理，取消跨设备 workspace 自动同步，保留历史操作记录供安全恢复。
- 录音按明确的服务预算规划 ASR 请求，保存完整确认区间，未知结果不自动重放；说话人证据独立保存，全文生成并审核纪要，可显式选择模型仅生成新版总结。
- 飞书发布使用保存正文的固定快照、明确位置与通知对象、精确 operation/job 回执和单面板确认；插件安装启用与账号授权分离。MCP 翻译保留独立确认与未知结果核验。

## 验收与边界

本次主线程在 Android 手机和原生飞书中完成的脱敏事实见 [App 飞书实发验收](../reviews/2026-10-17-app-feishu-acceptance.md)。这不替代全产品、群通知或 iOS 验收。

- iOS 原生说话人能力需要 macOS/Xcode/Pod 构建和真机验收；Windows 离线 C 核心与模拟桥接测试不能证明 iOS 已完整成功。
- Release 的链接/文件内容处理服务目前明确未配置。构建脚本没有注入该地址，也不借用 VILab 或飞书服务作为 fallback；已保存内容和录音原有链路不以此作为同步门禁。
- 本轮没有重新运行 Android/iOS 原生大构建、下载模型、操作设备或执行云端调用。依赖目录仅为离线验证复用，未作为制品提交。
