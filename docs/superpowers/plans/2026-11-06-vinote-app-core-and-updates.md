# VINote App 核心链路与 Android 更新 Implementation Plan

**Goal:** 使 App 的录音、会议、笔记、进度和飞书流程与当前桌面产品一致，并支持 Android 正式版更新。

**Architecture:** App 继续保留当前账号隔离的本机资料，按 VILab 服务的实际能力选择录音任务协议；本地任务记录与更新检查独立维护。Android 更新以公开 Release 元数据、可信签名及系统安装为边界。

**Tech Stack:** React Native 0.87、TypeScript、Android Kotlin、VILab、GitHub Releases。

**Spec:** 用户本轮确认的桌面功能对齐及 Android 公开仓库更新方案；实施记录见 `documents/dev_log/2026-11-06/2026-11-06_190000_wugui_无Issue_App核心链路与更新/index.md`。

## 全局约束
- 保留用户账号、文件与已安装 App 数据；不擅自开启跨设备同步。
- 确认服务能力与原任务身份后调用，未知结果不得重复提交。
- 不伪造任务进度、说话人身份或更新安装成功。
- 每项变更执行相应回归，真实手机及服务验证与离线测试分别记录。

## 任务
- [ ] 启动 Metro 和手机调试包；使用用户提供的音频核验录音及生成链路。
- [ ] 对齐 VILab 整段会议转写及既有流式录音策略，验证异步任务恢复。
- [ ] 完善多任务、状态、通知和准确可恢复的失败提示。
- [ ] 以已验证的关联关系实现会议、纪要及原文件的选择性删除。
- [ ] 完善 Android 更新检查、下载、签名验证、系统安装及发布脚本和文档。
- [ ] 核查笔记来源、飞书发布和手机界面的完整交互并真机验收。
