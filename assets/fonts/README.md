# Noto Sans SC

`NotoSansSC-Regular.ttf` is a static weight-400 instance of the Google Fonts Noto Sans SC variable font, distributed under the SIL Open Font License in [OFL.txt](OFL.txt).

- Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Retrieved 2026-10-11 from https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
- Generated using fontTools `instantiateVariableFont` with `wght=400`.
- Static file SHA-256: `028a6826552d2ab32eeDE9D4243381351382a154f974d96cac543fc571570407` (case-insensitive).

Android registers the bundled asset as `VINoteSans`; iOS registers its `NotoSansSC-Regular` PostScript name. `AppText` and theme input/Markdown styles use this family so an Android theme font does not replace product typography. System font scaling remains enabled. Changing the asset or native registration requires rebuilding the app; Metro Fast Refresh only updates JavaScript styles.
